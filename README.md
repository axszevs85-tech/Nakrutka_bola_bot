# Gnom Tycoon Bot
Bu Telegram bot "Gnomlar o'yini" (Piramida) asosida yaratilgan.

## Funksiyalar
- Gnom sotib olish
- Balansni to'ldirish
- Pul chiqarish
- Holatni tekshirish

## O'rnatish
1. `pip install -r requirements.txt` buyrug'ini bajaring.
2. `main.py` faylidagi `API_TOKEN` qatoriga o'z tokeningizni yozing.
3. `python main.py` orqali ishga tushiring.
